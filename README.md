# Корни · семейный архив Беларуси

Публичный сайт документального исследования. Статическая сборка без сторонних зависимостей и аналитики.

- `dist/index.html`, `style.css`, `app.js`: интерфейс.
- `dist/data/research.json`: публичный набор, источник интерфейса, включая предоставленные владельцем семейные ФИО/даты.
- `dist/report.html`: подробный публичный отчёт.
- `dist/downloads/`: полные опубликованные реестры и публичный ZIP.

Предоставленные владельцем семейные ФИО, даты и связи опубликованы по его прямому указанию. Дополнительные непубличные данные о живых людях не собирались. Исходный ZIP, файлы учётных данных, секреты и черновики отправок в репозиторий не включаются. Новые исторические находки добавляются с A-ID, C-ID, происхождением, статусом и ограничениями; кандидат не становится родственником по совпадению фамилии. Каждое обновление публикуется как новая версия того же сайта.
