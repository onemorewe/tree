# Корни · семейный архив Беларуси

Документальное генеалогическое исследование семей Зеленковых, Федоровичей, Каховских, Степутенко/Комаровых и Королёвых.

Публичный сайт для семьи. Предоставленные владельцем исходного дела ФИО, даты и связи публикуются по его прямому указанию. Все исходные варианты и противоречия сохранены. Новые непубличные данные о живых людях не собирались.

Исследование: 28 записей о людях, 60 артефактов, 115 утверждений, 23 связи (включая одну контактную категорию), 227 записей журнала. Новых родственников, документально соединённых с информантом: 0.

`single-source` — одна доказательная цепочка, не независимое подтверждение. Однофамильцы ведутся отдельно. Каталожное описание не считается прочитанным делом.

Статический сайт без внешних зависимостей, аналитики и входа. Публикация GitHub Pages из ветки main, корневая папка. Данные — `data/research.json`; полный отчёт — `report.html`; реестры — `downloads/`.

Методика: https://github.com/DenisSergeevitch/ex-ussr-kinship-research (v1.1.0, commit 5a430a2e8eb11ccf45ef8ed8e49c6abb8a1436d0).

Оригинальный частный ZIP, учётные данные и черновики архивных отправок не публикуются. Архивные запросы не отправлены, третьи лица не контактировались.
